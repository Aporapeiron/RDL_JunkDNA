# [B-ξ] 局所完備と終端閉包

## 断片

`∀B_finite : ξ(B) ≠ 0` を考えるとき、最初に切り分ける必要があるのは、

```text
B 内部で現在要求されている記述が完了した
```

ことと、

```text
関係全体が終端的に閉包した
```

ことは同じではない、という点。

したがって、

```text
Complete_B(D) = true
```

と

```text
ξ(B) ≠ 0
```

は両立しうる。

これは「有限な記述には必ず書き漏らしがある」という意味ではない。

## 部屋の内側と外側

部屋を B として切る。

部屋内部の備品、寸法、温度などを、現在の用途に必要な範囲で完全に記述することはできる。

しかし、その記述完了から、

```text
部屋に関係するすべての関係が閉じた
```

とは言えない。

壁を越える熱、音、光、振動、配線、配管、人の出入り、時間変化などがある。

重要なのは、ξ を「部屋の中の数え忘れ」としないこと。

```text
内部記述完了
≠
関係全体の終端閉包
```

## 有限グラフ

有限グラフ

```text
G = (V, E)
```

について、V と E を完全に列挙することはできる。

その意味ではグラフ記述は完備しうる。

しかし、ここで完備しているのは、採用した定義・語彙・関係型に対してである。

到達可能性、距離、同型、生成規則、別表現、観測者がそのグラフをどう切り出したかなど、別の関係軸を導入すれば新しい関係が立つ。

したがって、有限グラフは `[B-ξ]` の反例と即断できない。

## 純正な音程関係

局所的には非常に硬い関係を作れる。

```text
完全五度 = 3:2
長三度   = 5:4
```

しかし、純正な五度を12回積み上げても7オクターブとは一致しない。

```text
(3/2)^12 ≠ 2^7
```

ここで見えるのは、

```text
局所剛性
≠
大域的・終端的閉包
```

という構造。

平均律は「誤り」ではなく、局所的な比率の硬さを少し緩めて、大域接続性を得る設計と見られる。

この直感は RDL の非閉包性を考える初期動機の一つ。

## 帰納性と自己適用

`[B-ξ]` は、部屋、記述、数学、観測、音律、時間、言語など多くの領域で繰り返し現れる構造から、帰納的に強く支持される。

ただし、その帰納自体も有限である。

```text
[B-ξ] を支持する証拠群
      ↓
有限な説明境界 B_explanation
      ↓
ξ(B_explanation) ≠ 0
```

したがって、

```text
[B-ξ] を高重みで採用する
```

ことと、

```text
[B-ξ] を外部保証された終端真理にする
```

ことは分ける。

将来、

```text
∃B_finite : ξ(B) = 0
```

を強く示す構成が出れば、B4 自体を再検査する。

## 暫定圧縮

> **有限境界 B の内部で記述が完了することはありうる。しかし、その局所完備性を、関係全体の終端的完備性へ昇格させることは別問題である。RDL はこの昇格を標準では許さず、未回収関係 ξ を残す。さらに、その判断自身も有限な B によるものとして自己例外化しない。**
